### 検査中に見つけて直した不具合

| 事象 | 原因 | 対処 |
|---|---|---|
| `/price` `/facility` `/flow` で横スクロールが出る（601〜1024px） | `.cta` の負のマージン `-32px` が、`.page-panel`（padding 32px）だけでなく panel を使わない下層ページにも当たっていた。container の padding（16〜24px）より広く外へはみ出していた | 負のマージンを `.page-panel .cta` に限定し、panelなしのページは `padding` で内側に収める形に変更（`styles/globals.css`） |
| 固定バーの文字が読めない | 濃紺の帯の上に `--color-text-muted`（暗いグレー）を載せていた | 帯の中は `--color-on-primary`／リンクは `--color-primary-light` に変更（17.59:1／12.58:1） |
| トップの連番「01/02/03」と404の「404」がほぼ見えない | `--color-primary-light` が地の色に対し1.33:1 | `--color-primary` に変更（5.71:1） |
| `/404` に `h1` がなかった | 数字の `<p>` だけで見出しがなかった | `<h1>` を追加し、数字は `aria-hidden` の装飾に変更 |

## 4. トラブル事例と再発防止策

| 事例 | 再発防止策 |
|---|---|
| ローカル検査を `file://` で行い、CSSが当たっていない状態のスクリーンショットを見ていた | 静的書き出しの検査は必ずHTTPで配信して行う（`/_next/...` は絶対パスのため `file://` では解決できない） |
| 検査用ポート（4321・4399）が別プロジェクトのサーバーに使われており、他サイトを検査していた | 検査の最初に、配信中のHTMLへ屋号（`AOZORA FITNESS`）が含まれるかを `curl` で確認してから計測を始める |
| `.cta` の負のマージンが panel の padding 依存だった | 負のマージンを使う箇所は、依存する padding と同じ値であることをコメントに明記し、適用対象を限定する |
