# デザイン方針｜fitness-c（地域密着型フィットネスジム）

このサンプルサイトの配色・レイアウト・文言のトーンを定めた指定書です。実装は本書に従います。
配色を変えるときは、必ず本書のコントラスト比の表も更新してください。

## 1. コンセプト

**「気軽さ・継続しやすさ」**

はじめて通う人が最初に気にするのは、器具の使い方でも設備の数でもなく、
「自分が行っても浮かないか」「続けられなかったらどうなるか」です。
このサイトは、その2点への答えを先に出す情報設計にしています。

- 運動がはじめての人向けの案内があること（入会後1か月の使い方サポート）
- やめるときに困らないこと（契約期間の縛りなし・休会あり・違約金なし）
- 見学・体験が無料で、その日に決めなくてよいこと

強い言葉で鼓舞するトーン（「限界を超えろ」等）は使いません。近所の人が普段着で入れる場所として、
説明の言葉づかいは終始ていねいな敬体に統一します。

### 屋号（架空）

**AOZORA FITNESS（アオゾラフィットネス）つつじヶ丘店**

明るく開放的なブルーの配色と結びつけやすく、ひらがなに開いても読みやすい名称にしました。
所在地・電話番号は架空の値（`東京都調布市つつじヶ丘0-0-0` / `03-0000-0000`）です。

## 2. 配色（ブルー×白）

`styles/globals.css` の `:root` にある変数だけで配色を管理します。個別クラスへの直書きは禁止です。

| 変数 | 値 | 用途 |
|---|---|---|
| `--color-primary` | `#1467a5` | リンク・ボタン・アクセント |
| `--color-primary-dark` | `#0f4e7d` | ホバー・強調見出し・バッジ文字 |
| `--color-primary-light` | `#c7ddef` | 枠線・淡い塗り・区切り線 |
| `--color-primary-surface` | `#f1f6fb` | バッジ等の最も淡い面 |
| `--color-bg` | `#ffffff` | 地の色 |
| `--color-surface` | `#f7fafd` | カード・パネルの面 |
| `--color-text` | `#1d2530` | 本文 |
| `--color-text-muted` | `#4f5a67` | 補足文 |
| `--color-text-faint` | `#5f6975` | 注記・フッターの細字 |

### コントラスト比（WCAG 2.1 / AA基準 4.5:1）

| 前景 | 背景 | 比 | 判定 |
|---|---|---|---|
| `--color-primary` #1467a5 | `#ffffff` | 5.98:1 | 合格 |
| `--color-primary` #1467a5 | `--color-surface` #f7fafd | 5.71:1 | 合格 |
| 白 `#ffffff` | `--color-primary` #1467a5（ボタン） | 5.98:1 | 合格 |
| `--color-primary-dark` #0f4e7d | `#ffffff` | 8.73:1 | 合格 |
| `--color-text` #1d2530 | `#ffffff` | 15.45:1 | 合格 |
| `--color-text-muted` #4f5a67 | `--color-surface` #f7fafd | 6.70:1 | 合格 |
| `--color-text-faint` #5f6975 | `--color-primary-surface` #f1f6fb | 5.13:1 | 合格 |
| 白 `#ffffff` | 固定バー `rgba(8,24,40,.94)` | 17.59:1 | 合格 |
| `--color-primary-light` #c7ddef | 固定バー `rgba(8,24,40,.94)` | 12.58:1 | 合格 |

**明るさの根拠**：面の塗り分けを `#ffffff` と `#f7fafd` のごく薄い差だけで行い、
枠線も淡いブルーに寄せることで、影の少ない開放的な見え方にしています。
濃い色は、ボタン・見出しのアクセント・ヒーローのスクリムに限定します。

## 3. レイアウト

- コンテナ幅：本文 960px／トップとヘッダー・フッターは 1180px（`.container--wide`）
- 角丸は `--radius-lg: 14px` とやや大きめ。影は浅く（`--shadow-sm`）、圧迫感を出さない
- トップは画面幅いっぱいの帯（`.home-stripe`）を縦に積む構成。1つおきに `--color-primary-surface` 相当で塗り分ける
- カードは3列（`card-grid--3`）を基本にし、文章量の多いプログラム・設備は2列（`card-grid--2`）

### トップページの並び順

情報の並びは「不安をほどく → 施設の性格 → 内容 → 金額 → 行き方 → 疑問」の順にしています。

1. ヒーロー（「運動、はじめてで大丈夫。まちのジムです。」＋ 見学導線）
2. はじめての方から、よくお聞きすること（不安3点への回答）
3. 画像バンド ＋ 選ばれる理由（3点）
4. ひとりでも、みんなとでも（コミュニティ感）
5. プログラム（抜粋4本）
6. 料金プラン（3プラン。「いちばん多いプラン」を枠線で強調）
7. 見学・体験の流れ（先頭3ステップ）
8. よくあるご質問（4件）
9. CTA

## 4. 文言のルール

- **健康・医学的効果の断定表現を使わない。**「痩せます」「健康になります」「肩こりが治ります」等は書かない。
  書けるのは「体を動かす習慣」「運動の機会をご提供する」までとする
- **利用者の声・体験談は、架空のものであっても掲載しない。** コミュニティ感は、掲示板・ラウンジ・
  少人数スタジオという「場の説明」で表現する
- 医療機関ではないことを `/price` `/faq` `/terms` に明記し、通院中の方には医師への確認を促す
- 数字（定員12名、月8,800円、徒歩5分など）を入れて、判断できる具体性を持たせる

## 5. 画像（後日追加する前提）

現時点で画像はリポジトリにありません。レイアウトは画像なしで成立するように作ってあります
（ヒーローとバンドの `<img>` は `alt=""` の装飾画像で、読み込めなくても文言は読めます）。

| パス | 用途 | 選び方 |
|---|---|---|
| `public/images/hero/home-hero{,-640,-1024,-1600}.webp` | ファーストビュー | 窓のある明るいフロア。人物は後ろ姿か、判別できない距離で |
| `public/images/band/band-01{,-640,-1024,-1600}.webp` | セクションの区切り帯 | スタジオまたはラウンジの引きの画 |
| `public/images/logo.png` | ロゴ（正方形・112px以上） | 青地に白抜き |
| `public/images/ogp.png` | OGP（1200×630・PNG） | ヒーローと同系の画に屋号を載せる |

画像を追加したら、`components/HeroBanner.js` の `srcSet` と `pages/index.js` の
`<link rel="preload">` の `imageSrcSet` を同じ内容に保つこと。
